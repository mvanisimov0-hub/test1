# Расчётный модуль «Строим для Вас»

Рабочее место менеджера отдела продаж: по запросу клиента подбирает технические решения здания
из металлокаркаса и сэндвич-панелей, считает каркас, смету и сроки, показывает здание в 3D
и формирует коммерческое предложение.

Это первый этап: прямоугольное здание (в том числе с несколькими пролётами, перекрытиями,
антресолью, кран-балкой, навес без стен). Данные хранятся в браузере менеджера.

## Что умеет

- **Шаблоны зданий**: хозблок, гараж, ангар, тёплый склад, магазин, АБК, производство,
  автосервис, сельхоз здание, навес.
- **Климат**: 58 населённых пунктов Санкт-Петербурга, Ленинградской, Псковской, Новгородской,
  Вологодской, Мурманской областей и Карелии — снеговой и ветровой районы, отопительный период,
  глубина промерзания. Любое значение правится в расчёте.
- **Каркас**: выбор технологии (сварной до пролёта 12 м, иначе КМ/КМД), расчёт поперечной рамы
  методом конечных элементов, сочетания нагрузок по СП 20, подбор сечений по СП 16 из сортамента
  (профильная труба, двутавр, швеллер), прогоны, связи, фахверк, подкрановые балки, перекрытия.
  На выходе — поэлементная ведомость металла и нагрузки на фундаменты.
- **Ограждение**: толщина панелей по теплозащите (СП 50), площади, фасонные элементы.
- **Фундаменты**: винтовые сваи, столбчатые, буронабивные, плита, фундамент заказчика.
- **Смета**: разделы, материалы и работы, наценки, скидка, НДС по выбранному юрлицу,
  ручная правка строк и свои позиции. Себестоимость и маржа видны менеджеру.
- **Документы**: КП и смета на печать (PDF через диалог печати браузера), смета в Excel,
  расчётная записка, план в осях и поперечный разрез.
- **3D**: обшивка в цветах RAL, каркас, «рентген».

## Важные оговорки

- **Цены в справочнике — ориентировочные заглушки.** Перед работой с клиентами их нужно заменить
  ценами компании в разделе «Цены». Реквизиты юрлиц и логотип задаются там же.
- **Расчёт каркаса предварительный.** Он выполнен по нормам, покрыт тестами на аналитических
  задачах, но не сверен с реальными проектами КМ. До такой сверки он служит основанием для КП
  и задания на проектирование и раздел КМ не заменяет. Допущения перечислены в разделе
  «Решения и расчёт».
- **Снеговые и ветровые районы** сняты с карт СП 20 мелкого масштаба. Для пунктов у границы
  районов принят больший район, в расчёте показывается предупреждение — значение нужно
  подтвердить по месту.
- **Грунт** задаётся одним числом (R0). Без изысканий фундаменты — оценка для КП.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
```

```bash
npm run dev
```

Сборка одним файлом, который открывается двойным кликом без сервера и интернета
(шрифты при отсутствии интернета заменяются системными):

```bash
npm run build:single
```

Результат — `dist-single/index.html`. Этот файл можно раздать менеджерам как есть.

Тесты расчётного ядра:

```bash
npm test
```

## Устройство

| Папка | Содержание |
|---|---|
| `src/domain` | Расчётное ядро без привязки к интерфейсу: модель данных, сортамент, нагрузки, МКЭ, проверки, смета. Переносится на сервер без изменений. |
| `src/state` | Состояние и хранилище. `Repository` — граница, по которой подключается общий сервер. |
| `src/ui` | Экраны: форма, 3D, записка, чертежи, смета, КП, справочники. |
| `tests` | Тесты: решатель рамы на аналитических задачах, сортамент против ГОСТ, равновесие, смета. |
| `scripts/probe.ts` | Диагностика: печатает подобранные сечения и массы по всем шаблонам. |

Ключевые файлы ядра: `fem.ts` (решатель), `frameModel.ts` (расчётная схема и загружения),
`sizing.ts` (сочетания и подбор сечений), `checks.ts` (проверки по СП 16),
`structure.ts` (каркас целиком и ведомость), `estimate.ts` (смета), `prices.ts` (цены по умолчанию).
